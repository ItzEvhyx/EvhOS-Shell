# Compatibility and dependency notes

This snapshot comes from a live customized CachyOS installation, not a clean-room install. Test it in a VM or a spare account before adopting it. Hyprland's Lua configuration interface, Quickshell, Qt/QML modules and layer-shell behavior are especially version-sensitive. NixOS has declarative system configuration and a read-only package store, so it requires distro-specific packaging for services, fonts and SDDM. Fedora and Arch may use different package names, versions and filesystem paths. No distro has been validated from a fresh install yet.

Core pieces: Hyprland with Lua config support; Quickshell/Qt 6 (including Qt Quick Controls, Qt 5 compatibility graphical effects, SVG, and multimedia as required); Python 3 with Pillow; `xdg-utils` for default file handlers; systemd user services; D-Bus; PipeWire/WirePlumber; and a Wayland portal. Optional integrations referenced by the config include `jq`, `socat`, `flock`, `wl-clipboard`, `cliphist`, `cava`, `matugen`, `grim`, `slurp`, `ffmpeg`, `gammastep`, `mpris-proxy`, `trash-empty`, and the selected terminal/applications. Some paths under `/usr/lib` are distro-specific. Review `snapshot/home/.config/hypr/hyprland/execs.lua` and all keybinds on the destination.

The shell's source resides under `snapshot/shell/src` and is installed to `~/.local/share/serpantinum/src`; its existing internal paths and environment variables deliberately retain the upstream name. Customization and user-specific configuration are mixed with the fork. `snapshot/home` is an allowlisted home-directory snapshot. No credential stores, clipboard, notes, calendar events or browser profile are intended to be included.

Current machine references include output `eDP-1`, a profile portrait, specific locally installed apps and a browser icon. Missing optional apps will need to be installed or bindings changed. The SDDM image, wallpaper, user avatar and some third-party fonts/sounds may have separate licenses or personal-content implications. Keep this repo private unless you have audited redistribution rights. The file `src/version.txt` links to the included parent version file.

Snapshot host versions: Hyprland 0.57.2, `quickshell --version` reported `noctalia-qs 0.0.12` (Arch package), Qt 6.12.0, CachyOS kernel 7.3.1. Match the actual provided QML/Quickshell feature set, not just a similarly named executable. The restore script was tested with two passes into a disposable directory, including backups and home-path substitution. A graphical session and real SDDM authentication have not been tested in a fresh install.

Exact captured package versions and wallpaper fallbacks are in `snapshot/metadata.json`. FFmpeg poster generation is tested with H.264 MP4 fixtures; playback also depends on Qt Multimedia codecs. Wallpapers use `Pictures/Wallpapers/Pictures` and `Pictures/Wallpapers/Videos`. The full personal media collection and excluded proprietary fonts need separate backups. Workspace focus tests use compositor fixtures; gesture direction and live blur have been exercised on the source desktop, not a clean destination.
